## Fix 1: Phát nhạc chậm/lỗi

**Root causes:**
1. Client `androidVr`+`safari` bị Google throttle năm 2025-2026  
2. Không có URL cache → mỗi lần play = 2-5 giây fetch manifest  
3. Không retry khi 403 → im lặng thất bại

**Giải pháp:**

```dart
// Đổi clients
ytClients: [
  YoutubeApiClient.ios,
  YoutubeApiClient.androidMusic,
  YoutubeApiClient.web,
]

// Prefer m4a audioOnly (nhỏ hơn, iOS-friendly, ít 403)
final m4aStreams = manifest.audioOnly
  .where((s) => s.codec.mimeType.contains('mp4'))
  .toList();

// Cache URL 25 phút (YouTube TTL thực tế ~6h)
static final Map<String, _UrlCacheEntry> _urlCache = {};

// Retry 3 lần exponential backoff
for (int attempt = 0; attempt < 3; attempt++) { ... }
```

**Files thay đổi:**
- `lib/youtube/yt_audio_resolver.dart` — client, cache, retry, m4a
- `lib/services/player/audio_player_service.dart` — loadingStream, errorStream
- `lib/blocs/player/player_cubit.dart` — isLoading, errorMessage state
- `lib/screens/player/mini_player_bar.dart` — spinner khi loading
- `lib/screens/player/full_player_screen.dart` — loading overlay
